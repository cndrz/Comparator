Help

Scope and limits

  • Groq only, free tier. GPT-OSS 120B/20B and Qwen3.8 27B, about 8,000 tokens/min and 1,000 requests/day. No GPT-4, Claude, or Gemini.
  • Small, single-turn answers. 800-token cap, no history, follow-ups, tools, files, or images.
  • The judge is an opinion. Another small model, not a benchmark. It can be wrong, biased, or a one-run sample.
  • Nothing is stored. Drafts sit in session storage, runs go to Groq, and the key ships in the page bundle.

How to use

  1. Pick a model and creativity per prompt.
  2. Write both prompts and the shared message.
  3. Press ↑ or Enter to run both.
  4. View an output, or copy the winner.

FAQ

Why shuffle the order?

Judges favour the first answer they read, so the order is swapped each run and the verdict mapped back.

Can A and B use different models?

Yes. Each prompt has its own model and creativity, so you can compare prompts, models, or both.
